# Criminal Detection System

A machine learning-based desktop application that detects and reports known criminals using face recognition technology. This project combines Python, OpenCV, Tkinter, and MySQL to build a robust security solution with role-based logins and real-time image capture.

## 🔍 Features

- Face detection and recognition using OpenCV
- Admin and center login panels (credentials stored in MySQL)
- Capture and match faces with a criminal database
- GUI built with Tkinter
- Secure authentication and database integration
- Built using Anaconda environment for ease of dependency management

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Libraries:** OpenCV, Tkinter
- **Database:** MySQL
- **Platform:** Anaconda (with Python packages)
